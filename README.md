# For You

A monochrome personal-letter experience built with static HTML, CSS and JavaScript.

## Architecture

```
foryou/
├── index.html
├── met.js
├── style/
│   └── met.css
├── asset/
│   ├── letter-close4.svg
│   ├── letter-open3.svg
│   ├── music/music.mp3
│   └── icon/
└── README.md
```

## UX flow

1. Cinematic envelope prelude.
2. Envelope click opens the letter and starts the existing music when the browser permits it.
3. Editorial hero section.
4. Long-form personal letter.
5. Interactive reminder timeline.
6. Three “Open When” cards with modal messages.
7. Quiet closing section and back-to-top action.

## Design system

- Black, charcoal, graphite, off-white and white only.
- Cormorant Garamond for the classic/luxury personality.
- Inter for navigation and supporting UI.
- Spacious editorial composition, thin borders, monochrome gradients and restrained shadows.
- Micro-interactions: reveal-on-scroll, envelope animation, music visualizer, cursor glow, card tilt and modal transitions.
- Responsive and reduced-motion friendly.
- No frontend framework required, so it remains GitHub Pages friendly.
